# Necropolis web app

Next.js 16 app: UI, API routes, the Sexton relayer and the pure-TS engines in `src/core`. See the [root README](../README.md) for the full picture.

```bash
npm install --legacy-peer-deps
cp .env.example .env.local
npm run dev      # http://localhost:3000
npm test         # vitest
npm run typecheck
```
